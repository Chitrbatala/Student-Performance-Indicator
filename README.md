## End to End Machine Learning Project
# 🎓 Student Performance Indicator

A Machine Learning web application that predicts a student's **Mathematics Score** based on academic and demographic information using a trained regression model.

## 🚀 Live Demo

🔗 [https://YOUR-RENDER-URL.onrender.com](https://student-performance-indicator-tub8.onrender.com/predictdata)

## ✨ Features

- Predicts students' Mathematics scores
- Interactive Flask web interface
- Data preprocessing pipeline
- Machine Learning model integration
- Live deployment on Render

## 🛠️ Tech Stack

- Python
- Flask
- Scikit-learn
- Pandas
- NumPy
- HTML, CSS
- Render

```bash

cd Student-Performance-Indicator
pip install -r requirements.txt
python app.py
```
